Design plan: Anime Watch (frontend-design skill)

Color (4 named values):
- base: #0F0F2B (deep indigo — not warm cream or pure black, specific to anime night/screen atmosphere)
- surface: #1A1A3A
- accent: #FF6B9D (sakura pink — avoids Anthropic terracotta #D97757 default)
- gold: #F4C542 (manga highlight)
- text: #F0F0F5 (soft white, not pure #FFF)
- secondary: #9A95B8 (lavender grey)

Type (two families, clearly distinct):
- Serif (font-serif) for display/headline — manga/editorial energy, carries personality
- Sans (font-sans) for body — legible, quiet
- Weight cap 600; no extrabold; line-height 1.65 body, 1.15 headlines

Layout:
- Hero: asymmetric image-led (banner right, text left). Two-tone headline: "The season's" primary, "most watched." secondary (lavender).
- Featured: image-first rows with hairline rules, not rounded card grid (rejects SaaS-card kit default).
- No numbered markers unless sequence (section headers have prose index lines only).
- No ALL-CAPS eyebrow labels above headings.
- Line length < 70ch for paragraphs.

Principles:
- Boldness in one place: large serif hero headline + banner. Everything else quiet.
- No gradients, no glow, no shadow elevation. Hairline borders (#1A1A3A) separate information.
- Motion: only image hover scale (functional, answers interaction) — no scattered fade-ups.
- Copy: active voice, no filler, conversational tone.
